# Ardoise · page téléphone

Saisie des cours (élève, date, heure, durée) et suivi des séances du mois pour
l'iPhone, compagnon de l'app Mac Ardoise.
Cette page ne contient aucune donnée : les élèves et les cours transitent par un
relais ntfy protégé par une clé saisie sur le téléphone, et restent sur vos appareils.
